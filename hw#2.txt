Для віришення технічного завдання другої домашньої роботи було приянто рішення підняти віртуальну машину на старому домашньому ноутбуці.
На ноутбуці вже було встановлено Oracle VirtualBox, зкріетчено 1 віртуальну машину, для потреб завдання #1( Fedora 42 server). Для другої
домашньої роботи вирішено використати vagrant. 
Встановлено vagrant, в директорії майбутної віртуальної машини(надалі вм), зроблено конфіг файл Vagratfile(скрін 1)
Запуск віртуалки на vagrant потребує ініціалізації виртуальної машини кожен раз, після завантаження ноутбуку. Тому написано 
bat-файл, який автоматизує процесс( при потребі можливо додати в автозавантаження, а без потреби - просто клікаю) (скрін 2)
Далі з допомогою гугла\chatgpt та якоїсь там матері встановлено GitLab CE сервер. 
По першу налаштовано на використання локальної ip адреси(/etc/gitlab/gitlab.rb). При першому вході були проблеми зі зманою пароля 
на root для GitlabCE. Вирішено за допомого Rails Console. В перші запуски GitLabCE підвішував всю вм, через брак ресурсів. Так як,
 розширяти ресурси на ноутбуці немає куди, питання вирішено оптимізацією витрат ресурсів GitLab'ом. Додано в файл конфигурації( скрин 3)
